# Контрольные версии FoodLab

## checkpoint-mvp-supabase

- Git-коммит: `460b878`.
- Назначение: исходная работающая версия перед проектированием пошагового меню.
- Реализовано: каталог из 20 блюд и пользовательские рецепты; расчёты; оценки; меню, покупки, запасы; локальное хранение и собственный Supabase с RLS.
- Проверки на момент сохранения: 18 модульных, 8 браузерных, live API-проверка двух аккаунтов, сборка/типы, создание pg_dump.
- Ограничения: нет подключённого ИИ и магазинных цен; основная/тестовая постоянная публикация не настроены; SMTP/почтовое восстановление не включены.
- Контрольная точка хранит код, а не содержимое PostgreSQL. БД, согласованные резервные копии и секретная конфигурация runtime сохраняются отдельно.
- Пока сохранено локально в этой рабочей среде. Отправка на GitHub и публикация релиза не выполнены.

Для возврата кода следует сначала сохранить текущую работу, проверить совместимость схемы БД и выбрать эту контрольную точку. Для уже опубликованного продукта предпочтительно переключить подготовленную совместимую сборку, сохранив текущие пользовательские данные. Нельзя без отдельного решения выполнять разрушительный Git reset, удалять runtime или восстанавливать всю БД только ради отмены изменения интерфейса.
